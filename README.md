# web_vlc

Local video and audio player.

## Installation

1. Download the release for your operating system.
2. Extract the archive.
3. Open `Open web_vlc`.
4. Select a media folder.

- Windows: `Open web_vlc.vbs`
- Linux: `Open web_vlc`

## Source installation

Install Node.js 20–26.

```bash
git clone https://github.com/rayfromroblox/web_vlc.git
cd web_vlc
npm start
```

Run `npm start` to open web_vlc in a browser.

## Releases

Push a tag such as `v3.0.0`. GitHub Actions builds the Windows and Linux archives.
